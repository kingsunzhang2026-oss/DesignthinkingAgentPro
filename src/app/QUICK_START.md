# 🚀 快速开始指南

## 5 分钟集成 DeepSeek API

### 第一步：获取 API 密钥 (1 分钟)

1. 访问 https://platform.deepseek.com
2. 注册/登录账号
3. 点击 "API Keys" → "Create API Key"
4. 复制生成的密钥（格式：`sk-xxxxxxxx...`）

### 第二步：配置密钥 (1 分钟)

1. 在应用中点击左侧 **⚙️ 设置** 按钮
2. 在 "API 密钥 (DeepSeek)" 区域粘贴密钥
3. 点击 **"测试密钥"** 按钮
4. 看到 ✅ "API 密钥有效" 后点击 **"保存设置"**

### 第三步：生成场景 (2 分钟)

1. 关闭设置窗口
2. 在右侧 **"情境扩展节点"** 面板中
3. 点击 **"AI 模拟长尾场景"** 按钮
4. 等待 5-15 秒
5. ✅ 查看生成的 2-3 个 AI 场景！

## 🎯 可选：上传知识库 (1 分钟)

如果要基于特定文档生成场景：

1. 打开 **⚙️ 设置**
2. 在 "AI 知识库" 区域点击上传
3. 选择 TXT 或 MD 格式的文档
4. 等待处理完成
5. 关闭设置窗口
6. 再次点击 "AI 模拟长尾场景"

> **注意：** PDF 和 DOCX 文件需要先转换为 TXT 或 MD 格式才能完整解析。

## 💡 使用技巧

### 获得更好的场景

1. **使用具体的设备名称**
   - ✅ "小钳智能双极电刀 V2"
   - ❌ "电刀"

2. **上传相关文档**
   - 设备说明书
   - 国标、行标
   - 设计规范

3. **多次生成**
   - AI 生成有随机性
   - 可以多试几次选最好的

### 文档格式转换

**PDF → TXT:**
- Adobe Reader: 文件 → 另存为文本
- 在线工具: https://www.zamzar.com

**DOCX → TXT:**
- Microsoft Word: 文件 → 另存为 → 纯文本 (.txt)
- Google Docs: 文件 → 下载 → 纯文本

## 🔧 常见问题

### Q: "未配置API密钥" 错误？
**A:** 点击设置按钮，在 API 密钥区域输入密钥并测试。

### Q: "API密钥无效" 错误？
**A:** 检查：
1. 密钥格式正确（sk-开头）
2. 账户余额充足
3. 网络连接正常

### Q: 生成很慢或失败？
**A:** 检查：
1. 网络连接
2. 知识库文档是否过大（建议 < 5MB）
3. 重试生成

### Q: 上传的 PDF 没有被使用？
**A:** 当前版本 PDF 需要转换为 TXT/MD 格式才能完整解析。
